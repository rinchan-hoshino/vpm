# THE_cattail

VRChat Creator Companion packages by THE_cattail.

- Listing: <https://vpm.k-neco.com/>
- Repository: <https://vpm.k-neco.com/index.json>
- Package: [AFK Motion Patcher](https://github.com/k-neco-lab/afk-motion-patcher)

The site uses the standard [`vrchat-community/template-package-listing`](https://github.com/vrchat-community/template-package-listing) structure and publishes the validated static files in `Website/` through GitHub Pages.

## Release validation

Before publishing an update:

1. verify the repository URL, package URL, version, and SHA-256 in `Website/index.json`;
2. verify that `Website/index.html` and `Website/app.js` use the same repository and package metadata;
3. test Add to VCC, Copy, and Package Info in a local static preview;
4. confirm the GitHub Pages deployment, public `index.json`, and package download.
